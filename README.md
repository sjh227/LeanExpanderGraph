# ExpanderGraph

Lean formalisation of key definitions and foundational results in the theory of expander graphs. The formalisation was originally done as part of an Imperial College MSc project, and an abridged version of the accompanying [dissertation](LINK) serves as detailed documentation of the results. The key resource was [these lectures notes](https://people.seas.harvard.edu/\%7Esalil/cs225/spring09/lecnotes/Chap4.pdf).

## Installation

Follow [these instructions](https://lean-lang.org/install/) to get Lean and Mathlib. 

## Maintenance and contributing

There is one incomplete 'sorry-ed' proof. There are two further proofs that are 'sorry-ed' out which used to work
but now need fixing.

Beyond these, there is no roadmap for further results, but there are plenty of results not yet included (and, to my knowledge, not available elsewhere), so contributions are very welcome.

I don't envisage the project growing so large that I cannot maintain it myself. However, if it does, harmonisation and incorporation into a larger Lean library would be a sensible first step.
